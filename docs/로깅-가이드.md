# 로깅 가이드

## 🎯 초보자를 위한 설명

**로깅(Logging)**이란?
- 프로그램이 실행되는 동안 무슨 일이 일어나는지 기록하는 것
- `console.log` 대신 체계적으로 정보를 기록

**왜 필요한가요?**
1. 🐛 **디버깅**: 버그 발생 시 원인 파악
2. 📊 **모니터링**: 시스템 상태 추적
3. 🔍 **추적**: 사용자 행동 분석
4. 📈 **성능**: 느린 부분 찾기

## 📦 사용법

### 기본 사용

```typescript
import { logger } from '@/lib/logger';

// 정보 로그
logger.info('사용자가 페이지에 접속했습니다');

// 경고 로그
logger.warn('API 응답이 느립니다', { latency: 2000 });

// 에러 로그
logger.error('API 호출 실패', error);

// 디버그 로그 (개발 중에만 보임)
logger.debug('디버그 정보', { data: someData });
```

### 출력 결과 (개발 모드)

```
💡 [2025-01-15T10:30:45.123Z] [App] [INFO] 사용자가 페이지에 접속했습니다
⚠️ [2025-01-15T10:30:46.456Z] [App] [WARN] API 응답이 느립니다
{
  "latency": 2000
}
❌ [2025-01-15T10:30:47.789Z] [App] [ERROR] API 호출 실패
{
  "errorName": "NetworkError",
  "errorMessage": "Failed to fetch",
  "errorStack": "..."
}
```

### 프로덕션 모드 출력

```json
{"timestamp":"2025-01-15T10:30:45.123Z","level":"INFO","context":"App","message":"사용자가 페이지에 접속했습니다"}
{"timestamp":"2025-01-15T10:30:46.456Z","level":"WARN","context":"App","message":"API 응답이 느립니다","latency":2000}
```

JSON 형태로 출력되어 로그 수집 도구 (Datadog, Sentry 등)에서 쉽게 파싱 가능

## 🎨 컨텍스트별 로거

### 기본 제공 로거들

```typescript
import {
  apiLogger,      // API 관련
  dbLogger,       // 데이터베이스 관련
  agentLogger,    // AI 에이전트 관련
  ragLogger,      // RAG 검색 관련
  metricsLogger   // 메트릭 수집 관련
} from '@/lib/logger';

// API 로그
apiLogger.info('POST 요청 수신', {
  endpoint: '/api/agent-orchestrator',
  userInput: 'create automation'
});

// 데이터베이스 로그
dbLogger.debug('쿼리 실행', {
  table: 'automation_requests',
  operation: 'INSERT'
});

// AI 에이전트 로그
agentLogger.info('Step A 시작', {
  model: 'gpt-4o-mini',
  tokens: 1500
});
```

### 커스텀 컨텍스트 로거

## ⏱️ 성능 측정

### createTimer 사용

```typescript
import { createTimer } from '@/lib/logger';

async function processData() {
  const timer = createTimer('데이터 처리');

  // ... 작업 수행 ...
  await fetchData();
  timer.log('데이터 조회 완료'); // 중간 로그

  await transformData();
  timer.log('변환 완료');

  timer.end(); // "데이터 처리 완료: 1234ms"
}
```

### measureAsync 사용

```typescript
import { measureAsync } from '@/lib/logger';

// 함수 실행 시간 자동 측정
const data = await measureAsync('API 호출', async () => {
  return await fetch('/api/data');
});
// 출력: "API 호출 완료: 567ms"
```

## 🔍 로그 레벨

| 레벨 | 용도 | 언제 사용? | 프로덕션 출력 |
|------|------|-----------|-------------|
| **DEBUG** | 디버깅용 상세 정보 | 개발 중 버그 추적 | ❌ (숨겨짐) |
| **INFO** | 일반 정보 | 정상 작동 로그 | ✅ |
| **WARN** | 경고 | 에러는 아니지만 주의 필요 | ✅ |
| **ERROR** | 에러 | 에러 발생 시 | ✅ |

### 레벨별 사용 예시

```typescript
// DEBUG: 개발 중 디버깅
logger.debug('사용자 입력 검증', { input: userInput });
logger.debug('RAG 검색 결과', { sources: ragSources });

// INFO: 정상 흐름
logger.info('자동화 생성 시작');
logger.info('3단계 처리 완료', { totalTime: 3500 });

// WARN: 문제 가능성 있음
logger.warn('API 응답 느림', { latency: 3000 });
logger.warn('캐시 미스', { key: 'user:123' });

// ERROR: 에러 발생
logger.error('데이터베이스 연결 실패', dbError);
logger.error('OpenAI API 에러', apiError, {
  model: 'gpt-4o',
  tokens: 5000
});
```

## 🛠️ 실전 적용 예시

### API 라우트

```typescript
// src/app/api/agent-orchestrator/route.ts
import { apiLogger, createTimer } from '@/lib/logger';

export async function POST(req: Request) {
  const timer = createTimer('자동화 생성');
  const requestId = Math.random().toString(36).substr(2, 9);

  apiLogger.info('요청 수신', { requestId });

  try {
    const { userInput, followupAnswers } = await req.json();

    apiLogger.debug('요청 데이터', {
      requestId,
      userInput: userInput.substring(0, 50),
      followupCount: Object.keys(followupAnswers).length
    });

    const result = await generate3StepAutomation(userInput, followupAnswers);

    timer.end();
    apiLogger.info('처리 완료', {
      requestId,
      cardsCount: result.cards.length,
      totalTokens: result.metrics.totalTokens
    });

    return NextResponse.json(result);

  } catch (error) {
    timer.end();
    apiLogger.error('처리 실패', error as Error, { requestId });

    return NextResponse.json(
      { error: '자동화 생성 실패' },
      { status: 500 }
    );
  }
}
```

```typescript
  agentLogger.info('Step A 시작', { userInput: userInput.substring(0, 50) });

  const result = await measureAsync('Step A 실행', async () => {
    // ... Step A 로직 ...
    return { flow, tokens, model };
```

### RAG 서비스

```typescript
// src/lib/services/rag.ts
import { ragLogger } from '@/lib/logger';

export async function searchWithRAG(query: string) {
  ragLogger.info('RAG 검색 시작', { query });

  try {
    const response = await fetch(TAVILY_API_URL, { ... });

    if (!response.ok) {
      ragLogger.warn('Tavily API 응답 오류', {
        status: response.status,
        statusText: response.statusText
      });
      throw new Error('검색 실패');
    }

    const data = await response.json();

    ragLogger.info('RAG 검색 완료', {
      query,
      sourcesCount: data.sources.length
    });

    return data;

  } catch (error) {
    ragLogger.error('RAG 검색 실패', error as Error, { query });
    throw error;
  }
}
```


### 3. 적절한 레벨 선택

```typescript
// API 호출 시작/완료 → INFO
logger.info('API 호출 시작');

// 중간 변수 값 → DEBUG
logger.debug('변수 값 확인', { data });

// 재시도 가능한 실패 → WARN
logger.warn('API 재시도', { attempt: 2 });

// 치명적 에러 → ERROR
logger.error('데이터베이스 연결 실패', error);
```
